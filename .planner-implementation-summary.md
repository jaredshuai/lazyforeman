## Feature Generation Strategy (Phase 2.1)

### One-to-One Mapping
- **Input**: Mission + Assertions
- **Output**: Features (1:1 ratio)
- **ID Format**: feat-001, feat-002, ...
- **Fulfills**: Single assertion ID per feature
- **Preconditions**: Empty array (dependency analysis deferred to Phase 2.2)

### Feature Structure
```typescript
{
  id: "feat-001",
  name: "Users can login with email and password",  // Truncated to 50 chars
  description: "实现断言：Users can login with email and password\n\n背景：Current system lacks authentication\n\n架构约束：\n- Use bcrypt for password hashing\n- Use Express.js for backend",
  fulfills: ["VAL-001"],
  preconditions: [],
  status: "pending",
  createdAt: "2026-01-01T00:00:00Z",
  updatedAt: "2026-01-01T00:00:00Z"
}
```

## Database Integration

### Features Table
```sql
CREATE TABLE features (
  id TEXT PRIMARY KEY,
  mission_id TEXT NOT NULL,
  name TEXT NOT NULL,
  description TEXT,
  status TEXT CHECK (status IN ('pending', 'in_progress', 'completed', 'failed')),
  fulfills TEXT,           -- JSON array of assertion IDs
  preconditions TEXT,       -- JSON array of feature IDs
  current_worker_session_id TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (mission_id) REFERENCES missions (id)
);
```

### JSON Serialization
- `fulfills`: `JSON.stringify(['VAL-001', 'VAL-002'])`
- `preconditions`: `JSON.stringify(['feat-001'])`
- Deserialization on read for features.json export

## Next Steps (T2.1.6: Coverage Validator)

The Coverage Validator should verify:
1. **Completeness**: All assertions have exactly one claiming feature
2. **No Orphans**: No assertion is unclaimed
3. **No Duplicates**: No assertion is claimed by multiple features
4. **Pre-work Gate**: Block execution if validation fails

Suggested implementation:
```typescript
interface CoverageValidationResult {
  valid: boolean;
  orphanedAssertions: string[];     // Assertions with no claimer
  duplicateClaims: Map<string, string[]>;  // Assertion → Feature[] (length > 1)
  coveragePercentage: number;
}

function validateAssertionCoverage(
  assertions: Assertion[],
  features: Feature[]
): CoverageValidationResult;
```
