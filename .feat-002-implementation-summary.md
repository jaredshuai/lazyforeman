**Key Features:**
```typescript
interface GrillOptions {
  maxTurns?: number;
  useWayfinder?: boolean;      // Enable/disable Wayfinder
  wayfinderConfig?: {
    projectPath?: string;
    exploreDepth?: number;
  };
  outputPath?: string;
}
```

- Wayfinder is called when:
  - `useWayfinder: true` option is set
  - User input contains keywords like "现有", "基于", "扩展", "existing", "based on", etc.
  
- Graceful error handling:
  - If Wayfinder fails, logs warning and continues
  - Adds fallback message: "⚠️ 架构探索失败，请手动补充现有组件信息"
  - Never blocks mission generation

### Usage Example

```typescript
import { GrillAgent } from './src/grill/agent.js';
import { createWayfinderClient } from './src/wayfinder/client.js';
import { openDatabase } from './src/db/connection.js';

const db = openDatabase();
const wayfinder = createWayfinderClient(db, { 
  projectPath: process.cwd(),
  enableCache: true 
});

const agent = new GrillAgent(
  { 
    useWayfinder: true,
    wayfinderConfig: { exploreDepth: 3 }
  },
  wayfinder
);

const missionMd = await agent.generateMission(
  "在现有的认证系统基础上添加 SSO 功能"
);

console.log(missionMd);
// Output:
// # Mission: 在现有的认证系统基础上添加 SSO 功能
// 
// ## 背景
// ...
// 
// ## 架构约束
// - 现有组件：auth（3 个文件，路径：src/auth/service.ts）
// - 现有组件：models（2 个文件，路径：src/models/user.ts）
// - 架构探索工具：codegraph
```
